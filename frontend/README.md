# Tweak

Tweak is an internal productivity tool that helps support engineers manage customer cases, generate email templates, and streamline daily support operations.

## Features

- Create & manage support cases
- Quick Template Library
- Rich Email Editor
- Customer Time Zone Converter
- Powerful case search
- Local storage persistence
- Modern enterprise UI

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- TipTap Editor

## Getting Started

git clone https://github.com/ramdhivakar/tweak.git
cd tweak/frontend
npm install
npm run dev

Open:

http://localhost:5173
